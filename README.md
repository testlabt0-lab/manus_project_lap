# MediCare Pro

واجهة ويب عربية متجاوبة باتجاه RTL لمنصة تنسيق الزيارات المنزلية الطبية. تُظهر النسخة الحالية تجربة المريض ولوحات تشغيل العيادة والفريق الطبي ومركز الوثائق، وهي **نموذج وظيفي أولي** يعتمد بيانات تجريبية آمنة فقط.

## ما الذي يتضمنه المشروع؟

| المجال | المتاح في النسخة الحالية |
|---|---|
| تجربة المريض | لوحة رئيسية، حجز متعدد الخطوات، قائمة زيارات، تفاصيل زيارة، تقرير وفاتورة مقفلان حتى اكتمال الزيارة. |
| تشغيل العيادة | قائمة طلبات تجريبية، تعيين فريق، مؤشرات تشغيلية، وتبديل دور العرض. |
| الفريق الطبي | مهمة حالية وتحديثات حالة منضبطة وفق مسار الزيارة. |
| الأمن في الواجهة | عرض توضيحي لـRBAC وJWT وRLS، وإغلاق التقرير والفاتورة حتى حالة `COMPLETED` والقدرة المصرح بها. |
| مركز المعرفة | معاينات DFD وSequence Diagram وERD، وتنزيل حزمة المصدر والوثائق. |
| الجودة | اختبارات Vitest لمنطق انتقال الحالة وإتاحة المخرجات وسلامة بيانات العرض التجريبية. |

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

لفحص الأنواع وتشغيل الاختبارات:

```bash
pnpm check
pnpm test
```

## هيكل مهم

```text
client/src/pages/Home.tsx  # واجهات التطبيق ومسارات العرض التجريبي
client/src/index.css       # نظام تصميم RTL والمتجاوب
shared/medicare.ts         # مسار حالات الزيارة وقدرات الإتاحة
shared/mockData.ts         # بيانات تجريبية آمنة مشتركة
shared/*.test.ts           # اختبارات المنطق وبيانات العرض
```

## ملاحظة أمنية

هذه النسخة لا تجمع معلومات صحية أو بيانات دفع أو عناوين فعلية. تستخدم تسميات مثل «مريض تجريبي» و«حي تجريبي». عند الانتقال إلى بيئة إنتاج، يجب ربط الواجهات بخادم موثق وقاعدة بيانات معزولة، وتطبيق التحقق الخادمي الفعلي لـRBAC وJWT وRLS وعدم اعتبار منطق الواجهة بديلاً عن الحماية الخادمية.

## وثائق المشروع

يحوي جذر المشروع وثائق التخطيط، ونظام التصميم، ورحلة المريض، وتصميم قاعدة البيانات وERD. كما يمكن تنزيل نسخة مضغوطة من داخل مركز الوثائق في التطبيق.
